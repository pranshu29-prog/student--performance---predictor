# Student Performance Predictor

A Machine Learning project that predicts a student's final marks using study hours, attendance, and previous marks.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Linear Regression

## Features

- Predicts student final marks
- Uses Linear Regression
- Calculates Mean Absolute Error (MAE)

## How to Run

Install required libraries:

```bash
pip3 install -r requirements.txt
